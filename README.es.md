# ThermoGap

**Reutilización del calor residual para fabricar productos adicionales en la misma fábrica.**

[English](README.md)

ThermoGap es un concepto en fase de investigación. Evalúa si el calor que desecha un proceso puede servir para fabricar otro producto o alimentar otro proceso en la misma fábrica. Considera compatibilidad física, horarios, equipos, consumo de energía, costes e incertidumbre.

## Estado actual

**Investigar más. Todavía no existe software de producción.** La investigación encontró que las herramientas actuales ya cubren la búsqueda de fuentes y consumidores de calor, la integración de procesos y el almacenamiento por horarios. Para justificar un producto nuevo habría que demostrar una necesidad concreta, por ejemplo conectar el calor recuperado con un producto nuevo, su materia prima y su economía incremental. Esa ventaja es una hipótesis, no un resultado demostrado.

## Qué incluye la investigación

- Posibles fuentes y usos del calor residual industrial.
- Requisitos para fábricas nuevas y para adaptar fábricas existentes.
- Productos comerciales que podrían fabricarse en la misma fábrica.
- Límites de temperatura, horarios, tecnología y economía.
- Tres casos sintéticos y una revisión crítica.
- Evidencia y límites para Estados Unidos, Europa y Canadá.

## Etiquetas de evidencia

Los informes separan hechos verificados, supuestos de ingeniería, predicciones del modelo, hipótesis comerciales y preguntas pendientes. Los datos de los casos son sintéticos. No proceden de fábricas en operación. No se hizo ningún experimento ni despliegue industrial.

## Límites

El trabajo combina investigación documental y cálculos sintéticos que se pueden comprobar a mano. No es un modelo de software comparado de forma independiente, una auditoría de planta, un diseño de equipos ni una prueba de rentabilidad. Faltan precios, datos de operación, demanda de compradores y presupuestos de instalación de una fábrica concreta.

## Decisión

**INVESTIGAR MÁS.** Antes de crear un producto mínimo viable, hay que comparar los mismos casos transparentes con herramientas existentes.
